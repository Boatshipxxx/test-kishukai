# デザイン方向性の比較 — 案A「情」／案B「ATHLETIC」

同じ情報設計（`docs/BRANDING.md` / `docs/WIREFRAME.md`）の上に、見え方の異なる2案を用意しました。
**中身・コピー・差し替え項目は両案とも同一**です。選ぶのは「どう見せるか」だけです。

| | 案A「情」 | 案B「ATHLETIC」 |
|---|---|---|
| 実装 | 静的HTML＋CSS（`index.html` ほか7ページ） | React + Vite + Tailwind v4（`design-b/`、Figma Make向け） |
| 配色 | 生成りの白＋深いネイビー、太極の紅×青、金の差し色 | 黒×白×輝ゴールド（`#F4DE1E`）、太極の紅を副アクセント |
| 書体 | 見出し＝明朝、本文＝ゴシック | 見出し＝Oswald（英字コンデンス）、本文＝Noto Sans JP |
| 形 | 角丸14px、やわらかい影、余白広め | 角丸なし、ヘアライン罫、密度高め、色反転ホバー |
| 第一印象 | 温かい・信頼できる・教育的 | 力強い・現代的・競技志向 |
| ページ数 | TOP＋下層6ページ（完成） | TOP（1ページ）※方向性確定後に展開 |

## それぞれが効く場面

**案A「情」が向くケース**
- 主ターゲットが「はじめての習い事を探す保護者」で、安心感が決め手になる
- 制作概要の核である「情（ジョン）」「人間教育」「第二の家族」を前面に出したい
- 幼児〜小学生の入会を最優先で増やしたい

**案B「ATHLETIC」が向くケース**
- 子ども本人（特に小中学生）の「カッコいい」を最初のフックにしたい
- 選手育成クラス・大会実績・アクロバット系を強く打ち出したい
- 地域企業への協賛依頼で「本格的に活動している団体」に見せたい
- 大人向けクラス（カーディオ）やサブスク展開を将来的に伸ばしたい

## 判断のポイント

制作概要の優先度（①保護者 ②子ども本人 ③現会員 ④地域企業）に照らすと、
**主接点である保護者の安心感に直結するのは案A**です。
一方で、資料にあった「道場からスタジオへ」「敷居を下げて現代的に」という方向を
最も強く体現するのは案Bで、子ども本人と協賛企業への訴求力は案Bが上回ります。

折衷案として、**案Aをベースにしつつ、クラス一覧と遠征レポートだけ案Bの
高コントラストな見せ方（データ列・フィルタUI・大きな英字見出し）を取り込む**構成も可能です。
どの方向で進めるかご指定いただければ、その路線で全ページを揃えます。
