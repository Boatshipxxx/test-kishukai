# 輝蹴会 リブランディング — 全ページ ワイヤーフレーム仕様

`docs/BRANDING.md`（目的・ターゲット・接点優先度）を受けた、下層ページまでの構成設計書。
各ページに「主接点（一次CTA）」を1つだけ置き、TOPで整理した優先順位をページ単位でも守る。

## 0. 全ページ共通シェル

```
┌──────────────────────────────────────────────────────────────┐
│ ◉ 輝蹴会 / KISHUKAI TAEKWONDO ACADEMY   理念 挑戦 クラス お知らせ 協賛 [無料体験]│ ← sticky
├──────────────────────────────────────────────────────────────┤
│ PAGE HEAD（濃紺帯）                                            │
│  breadcrumb                                                   │
│  EYEBROW (英字ラベル)                                          │
│  ページタイトル（明朝）                                          │
│  リード文（1〜3行）                                             │
├──────────────────────────────────────────────────────────────┤
│ 本文セクション（白／薄青の交互）                                  │
├──────────────────────────────────────────────────────────────┤
│ CTAバンド（紅）— そのページの主接点                               │
├──────────────────────────────────────────────────────────────┤
│ FOOTER（濃紺）ブランド / サイトマップ / お問い合わせ               │
└──────────────────────────────────────────────────────────────┘
```

- ヘッダー右の `[無料体験]` は全ページ常設（優先度1＝保護者の主接点）
- 下層ページのCTAバンドはページごとに主接点を出し分ける（下表）
- 濃紺 → 白 → 薄青 → 濃紺 の面の切り替えでセクション境界を作る（罫線に頼らない）

| ページ | 主接点（CTAバンド） | 副接点 | 主ターゲット |
|---|---|---|---|
| TOP | 無料体験 | サポーター協賛 | 保護者＋子ども |
| 私たちの理念 | 無料体験 | クラス・料金 | 保護者 |
| 世界への挑戦 | 無料体験 | サポーター協賛 | 子ども＋保護者 |
| クラス・料金 | 無料体験 | よくある質問 | 保護者 |
| お知らせ | 無料体験（細） | — | 現会員・保護者 |
| サポーター | 協賛のご相談 | 活動実績 | 地域企業 |
| 無料体験申込 | フォーム送信 | — | 保護者 |
