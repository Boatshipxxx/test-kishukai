# 輝蹴会（きしゅうかい）リブランディング整理ドキュメント

対象サイト: https://kishusports.work/ のリブランディング・デモ制作用マスター資料。

**優先資料**: 「【輝蹴会】WEBサイト制作・ブランディング用基礎レポート」（制作概要）
**補完資料**: テコンドー普及とサブスクジム戦略（2点） — クラス編成・料金モデル・現代的スタジオ演出の参考として反映。

---

## 1. 目的整理（Why）

| レイヤー | 目的 |
|---|---|
| 上位目的 | 単なる格闘技道場ではなく「世界とつながり、豊かな人間性を育む武道アカデミー」としてのイメージ確立 |
| ブランド核 | 韓国の「情（ジョン）」×テコンドー精神（五大精神）の融合。世界テコンドー文化エキスポ（WTCE／韓国・茂朱）遠征経験を最大の強みとして打ち出す |
| サイトの役割 | 訪問者ごとに最適な情報を届け、次のアクション（①体験入会 ②応援・コミュニティ参加 ③協賛）へつなげる導線設計 |
| トーン刷新 | 「暗い・痛い・厳しい道場」→「明るく清潔で温かいスタジオ／アカデミー」へ。安全性・国際性・人間教育を前面に |

### ブランドキーワード
- **世界の人々と一つの精神体に** — 国境や言葉を越えるテコンドーファミリーの「情」の体験
- **強さと優しさの調和** — 百折不屈で身につけた力を、仲間を思いやり弱者を守る力へ
- **第二の家族としての道場** — 指導者・選手・保護者が「情」で結ばれるコミュニティ

### キャッチコピー（制作概要指定）
> 蹴り出す一歩が、世界へつながる。情ではじまるテコンドー

## 2. ターゲットと接点の優先順位（Who / Where）

制作概要のコミュニケーション設計をもとに、TOPページでの露出優先度を以下の通り定義する。

| 優先度 | ターゲット | 求める情報・心理 | サイト側の接点（コンテンツ・導線） | TOPでの扱い |
|---|---|---|---|---|
| **1** | 入会検討中の小中学生の保護者 | 安全に学べるか／費用は／どんな先生・仲間か | 世界大会遠征レポート（安心感と国際性の証明）、初心者Q&A、**体験入会フォームへの目立つボタン** | ファーストビューの主CTA。ヘッダー常設ボタン |
| **2** | 選手（子どもたち本人） | カッコいい蹴り／世界の友達と戦いたい | 躍動感ある写真・動画ギャラリー、技紹介、先輩インタビュー | ヒーロービジュアル＋ギャラリーセクション |
| **3** | 現会員・保護者コミュニティ | スケジュール／試合結果・活動報告 | お知らせ・ブログ、遠征報告、地域イベント告知 | NEWSセクション（更新性の担保） |
| **4** | 地域企業・スポンサー候補 | 地域貢献になるか／応援する価値があるか | 「輝蹴会サポーター（協賛）」専用ページ、地域スポーツ体験会の実績報告 | ページ下部に専用セクション＋副CTA |

**接点の結論**: TOPページの主接点は「体験入会」（保護者）、副接点は「サポーター協賛」（地域企業）。子ども本人の心を掴むビジュアル（ヒーロー・ギャラリー）が保護者CTAの説得材料になる、という構造にする。

## 3. サイトマップ（制作概要準拠）

1. **HOME（トップページ）** — 本デモの対象
   - メインビジュアル: WTCEでの子どもたちの笑顔と躍動感ある蹴り
   - キャッチコピー＋体験入会CTA
2. **私たちの理念（About Us）** — 五大精神（礼儀・廉恥・忍耐・克己・百折不屈）＋「情」ベースの指導方針
3. **世界への挑戦（遠征レポート）** — WTCE（韓国・茂朱）遠征記、国際交流エピソード
4. **クラス・料金案内（Programs）** — ジュニアクラス、選手育成クラス等
5. **輝蹴会サポーター（助成・協賛）** — 一口協賛の募集、財団助成・地域連携の紹介
6. お知らせ／ブログ（会員向け接点）

## 4. 補完資料からの反映事項（サブスク戦略）

制作概要を損なわない範囲で、以下をProgramsと料金に反映する。

- **クラス編成**（キッズ中心の道場実態に合わせ選定）
  - キッズ・デベロップメント（幼児〜小学生／礼儀＋コーディネーション）
  - ベーシック・テクニック（基礎・姿勢・型プムセ）
  - アクロバット・キック（540度キック等、若年層・SNS映え）
  - 選手育成クラス（防具着用ライトスパー、競技志向）
  - カーディオ・テコンドー（大人・保護者向け有酸素、非接触）
- **料金モデル**: ライト（月4回）／レギュラー（通い放題）／プレミアム（＋パーソナル）の3段サブスク
- **演出方針**: 「道場」→「スタジオ」。明るく洗練された空間・マイクロステップ制（ストライプ制度）による小さな達成感の可視化

※ 補完資料の「暗闇フィットネス」「FC展開」等の大人向けビジネス要素は、輝蹴会の「情・人間教育」ブランドと相反するためTOPデモでは採用しない（将来の大人向け展開の参考として保留）。
