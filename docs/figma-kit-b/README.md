## 移行フロー（SVGで持ち込む手順）

### STEP 0. 下ごしらえ（5分）

1. Figmaで新規ファイルを作成し、名前を `輝蹴会 リブランディング — 案B` にする
2. ページを3つ用意する
   - `01_スタイルガイド`
   - `02_TOP（PC）`
   - `03_TOP（SP）`
3. フォントを用意する。ブラウザ版Figmaなら**Figma Font Helper**（デスクトップ版なら不要）をインストール。使用フォントは2つとも**Google Fonts収録なので追加購入は不要**です。
   - `Oswald`（英字見出し）
   - `Noto Sans JP`（日本語・本文）

### STEP 1. スタイルガイドを取り込む（10分）

1. `01_スタイルガイド` ページを開く
2. `style-guide-b.svg` を**Finder/エクスプローラーからキャンバスへドラッグ＆ドロップ**
   - ※ メニューの「File > Import」ではなくドラッグ推奨。ドラッグだと**ベクターのまま**入り、`<g id="…">` が「カラーパレット」「タイポグラフィ」などの**日本語レイヤー名**として展開されます
3. 取り込んだら、そこから**Figmaスタイルを登録**する
   - 色スウォッチを選択 → 右パネル Fill の `::` → `+` で **Color style** として保存
     （`ink/黒` `paper/白` `fog/霧` `gold/輝` `blood/紅` の5つ）
   - テキスト見本を選択 → Text の `::` → `+` で **Text style** として保存
     （`H1/Oswald Bold` `H2/NotoSansJP Bold` `Eyebrow/Oswald 12` `Body/NotoSansJP 14`）
4. ボタン見本を選択 → 右クリック → **Create component**（`Btn/Gold` `Btn/Outline` `Btn/Black`）

> ここまでで「案Bの見た目のルール」がFigmaのスタイルとして使える状態になります。

### STEP 2. 参照画像を敷く（5分）

1. `02_TOP（PC）` ページで **Frame（F）** を作成。幅 `1440`、高さは仮で `6000`
2. `reference-desktop.png` をそのフレームにドラッグ＆ドロップ
3. 画像を選択して **幅1280・中央寄せ**、**Lock（⌘⇧L / Ctrl+Shift+L）** で固定
4. 透明度を `30%` 程度に下げる（この上に本番レイヤーを組むため）
5. `03_TOP（SP）` も同様に、幅 `390` のフレームへ `reference-mobile.png` を敷く

### STEP 3. セクションごとに組み直す（本作業）

参照画像をなぞる形で、上から順に組みます。**1セクション＝1 Frame**、Auto layout（縦・gap 64px）で積むと後の差し替えが楽です。

|---|---|---|

| 02 | ヒーロー（KICK TO THE WORLD） | Oswald Bold・行間0.86。下端に金黒ストライプ12px |
| 03 | 保護者への3つの約束 | 1pxヘアラインの3カラムグリッド |

| 05 | クラス一覧 | カード5枚＋体験誘導。**整理後はフィルタ削除予定** |
| 06 | 料金プラン | 3カラム・中央のみ黒反転 |

テキストは `copy-b.md` からコピペしてください。**太字の「整理後」注記があるセクションは、削減方針が確定してから組むと手戻りがありません**（ワイヤー `wf-b3-seirian2-sabetsuka.svg` が推奨構成）。

### STEP 4. ロゴをヘッダーに配置する

`style-guide-b.svg` の **「ロゴロックアップ（ヘッダー）」** レイヤーに配置仕様が入っています。

```
[ロゴ 56×56] ──16px── 輝蹴会（26px Bold）
                      KISHUKAI TAEKWONDO（10px Oswald・字間広め）
```

1. 実ロゴのSVG（または背景透過PNG）をキャンバスにドラッグ
2. 56×56のフレームに入れて **Fit** で収める
3. 社名テキストとまとめて選択 → **Auto layout（横・gap 16px・中央揃え）**
4. 右クリック → **Create component**（`Logo/Header`）にしておくと全ページで同期します

> ⚠️ **実ロゴのファイルをお送りください。** いただいた画像（鷲のエンブレム＋TAEKWONDO / KISHUKAI）は、作業コンテナの再作成でファイルが失われており、こちらで復元できませんでした。**SVG・AI・EPS・背景透過PNG（できれば512px以上）**のいずれかをご提供いただければ、Figma用に整えてキットへ同梱します。現在同梱の `logo-kishukai.svg` は仮の太極マークです。
> 黒背景のヘッダーに載るため、**白フチ付き or 背景透過**のデータが理想です。

### STEP 5. レスポンシブとコンポーネント化（仕上げ）

1. 繰り返し要素（クラスカード、料金プラン、ニュース行）を **Create component**
2. PC版で組んだフレームを複製 → 幅390に変更 → Auto layoutで縦積みに調整（SP版）
3. 完成したら **Share → リンク発行**でクライアント共有

## SVG取り込みの注意点

| 事象 | 対処 |
|---|---|
| テキストがアウトライン化されて編集できない | ドラッグ＆ドロップで取り込むと編集可能なテキストになります。それでも崩れる場合は `copy-b.md` からテキストを貼り直してください |
| フォントが置き換わる | `Oswald` / `Noto Sans JP` をFigmaで有効化（Google Fonts収録）。ブラウザ版は Font Helper が必要 |
| 色が微妙に違う | SVGはsRGB。Figma側のカラープロファイルを **sRGB** に設定 |
| レイヤーが大量に分かれる | グループ（`<g id>`）単位で選択 → 不要なら Flatten（⌘E）で統合 |
| 参照PNGを間違って動かす | STEP 2の **Lock** を必ず実施 |

## 素材の再生成

```bash
python3 scripts/build_figma_kit.py docs/figma-kit-b   # スタイルガイド・ロゴ
python3 scripts/build_wireframe_svg.py docs/wireframes # 構成ワイヤー
```

参照PNGとコピー原稿は `design-b` をビルドした実装から機械抽出しています（実装を更新したら再取得してください）。

## 未確定のまま残している項目

Figmaで組む際も、以下は**プレースホルダーのまま**にしておいてください。確定情報が届き次第まとめて差し替えます。

- 写真（すべてプレースホルダー。想定内容はキャプションに記載）
- 料金（入会金・月謝・年会費）
- 曜日・時間・会場・住所・電話番号
- 指導者の氏名・段位
- 遠征の日程・参加人数・成績
