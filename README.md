# 輝蹴会（きしゅうかい）リブランディング・デモサイト

https://kishusports.work/ のリブランディングに向けたデモです。ビルド不要の静的HTMLで、
`index.html` をブラウザで開けばそのまま全ページを回覧できます。

## ドキュメント

| ファイル | 内容 |
|---|---|
| `docs/BRANDING.md` | 目的整理・ターゲット別の接点優先度・サイトマップ・実装仕様（マスター資料） |
| `docs/WIREFRAME.md` | 全ページのワイヤーフレーム、ページごとの主接点、素材収集リスト |

## ページ

| ファイル | ページ | 主接点（CTA） |
|---|---|---|
| `index.html` | TOP | 無料体験 |
| `about.html` | 私たちの理念（五大精神と「情」・指導方針・指導者・クラスの流れ） | 無料体験 |
| `world.html` | 世界への挑戦（WTCE遠征レポート・遠征の記録・保護者の声） | 無料体験 |
| `programs.html` | クラス・料金案内（クラス・週間スケジュール・料金・昇級・入会の流れ） | 無料体験 |
| `news.html` | お知らせ（カテゴリ別記事一覧・運用方針） | 無料体験 |
| `supporter.html` | 輝蹴会サポーター（協賛プラン・掲出イメージ・活動実績・助成） | 協賛のご相談 |
| `trial.html` | 無料体験のお申し込み（流れ・フォーム・Q&A・アクセス） | フォーム送信 |

`assets/site.css` が全ページ共通のスタイル。カラー・タイポグラフィはCSS変数でトークン化し、
ライト／ダークの両テーマに対応しています。

## 資料の反映方針

1. **優先資料**: 「【輝蹴会】WEBサイト制作・ブランディング用基礎レポート」— コンセプト（情×五大精神）、キャッチコピー、ターゲット別導線、サイトマップはこの資料に準拠
2. **補完資料**: サブスクジム戦略（2点）— クラス編成・3段階料金モデル・「道場→スタジオ」の演出トーンを、キッズ中心の道場実態に合わせて取捨選択して反映

## 差し替えが必要な項目

デモのため、以下は仮の内容です。実データに置き換えてください。

- **写真**: すべてプレースホルダー（`figure.photo`）。`figcaption` に想定する写真の内容を記載済み
- **固有情報**: 住所・電話番号・会場・スケジュール・料金・指導者氏名・遠征日程は「（差し替え）」と明示
- **フォーム**: `trial.html` のフォームは未接続。送信ボタンでデモ用メッセージを表示するのみ
- **お知らせ記事**: デモ記事。カテゴリ絞り込みとページ送りは本番実装時に有効化

## スクリプト

```bash
# 下層6ページを再生成（ヘッダー・フッター・ナビの単一ソース）
python3 scripts/build_pages.py

# 全ページを1ファイルにまとめたレビュー用バンドルを生成
python3 scripts/build_artifact.py dist/demo-single.html
```

`index.html` は直接編集します。ヘッダー・フッター・ナビを変更した場合は、
`scripts/build_pages.py` 側の `BRAND` / `FOOTER` / `NAV` も合わせて更新し、再生成してください。
