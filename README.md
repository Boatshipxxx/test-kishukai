# 輝蹴会（きしゅうかい）リブランディング・デモサイト

https://kishusports.work/ のリブランディングに向けたデモです。

- `index.html` — TOPページのデモ（自己完結の静的HTML。ブラウザで直接開けます）
- `docs/BRANDING.md` — 目的整理・ターゲット別接点の優先度・サイトマップ・実装仕様のマスタードキュメント

## 資料の反映方針

1. **優先資料**: 「【輝蹴会】WEBサイト制作・ブランディング用基礎レポート」— コンセプト（情×五大精神）、キャッチコピー、ターゲット別導線、サイトマップはこの資料に準拠
2. **補完資料**: サブスクジム戦略（2点）— クラス編成・3段階料金モデル・「道場→スタジオ」の演出トーンを、キッズ中心の道場実態に合わせて取捨選択して反映

## 写真の差し替え

写真素材が未支給のため、ビジュアルは `figure.photo` のプレースホルダーで構成しています。各プレースホルダーの `figcaption` に想定する写真の内容を記載済みです。
