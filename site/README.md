# 輝蹴会 公式サイト（案B「ATHLETIC」）＋ CMS

Next.js（App Router）で構築したサイト本体と、テキスト・画像・バナーを差し替えるための管理画面です。
外部のCMSサービスは使わず、Vercelの中だけで完結します。

- 公開ページ: `/`
- 管理画面: `/admin`

---

## 公開までの手順（Vercelでの初期設定）

デプロイ自体はGitHubへのpushで自動的に走ります。**管理画面を使うには、次の2つの設定が必要**です。

### 1. 管理画面のパスワードを決める

Vercel のプロジェクト → **Settings → Environment Variables**

| Key | Value | 対象 |
|---|---|---|
| `ADMIN_PASSWORD` | 任意のパスワード（推測されにくいもの） | Production / Preview / Development すべて |

保存したら **Deployments → 最新のデプロイ → Redeploy** で反映します。

### 2. 保存先（Vercel Blob）を用意する

Vercel のプロジェクト → **Storage → Create Database → Blob** を選び、作成したストアを
このプロジェクトに **Connect** します。`BLOB_READ_WRITE_TOKEN` が自動で環境変数に追加されるので、
そのあと一度 **Redeploy** してください。

> 未設定でもサイトは表示され、管理画面も開けます。ただし編集内容と画像は保存されず、
> 管理画面の上部に「保存先が未設定です」と表示されます。

---

## 管理画面の使い方

`https://（サイトのURL）/admin` を開き、設定したパスワードでログインします。

- **左の一覧**がページの構成です。クリックすると右に編集フォームが出ます
- 各セクション右の**チェックを外すと、そのセクションをサイトから隠せます**（内容は消えません）
- **画像**は「画像をアップロード」から差し替えます。PNG / JPEG / WebP / SVG、8MBまで
- **繰り返し項目**（クラス・お知らせ・料金プランなど）は、`↑ ↓` で並び替え、`×` で削除、
  「＋ 追加」で増やせます
- 変更すると画面下に保存バーが出ます。**「保存する」を押した時点でサイトに反映**されます

### 編集できるもの

| セクション | 主な項目 |
|---|---|
| サイト全体 | 道場名・ロゴ画像・ヘッダーメニュー・タブのタイトル・説明文 |
| ヒーロー（最上部） | 背景バナー画像・大見出し・キャッチコピー・ボタン文言・実績の帯 |
| 3つの約束 | 漢字・見出し・本文（3件） |
| 世界への挑戦 | メイン写真・サムネイル3枚・引用文・遠征データ |
| クラス一覧 | クラスごとの写真・名称・対象・日時・月謝・説明（追加/削除可） |
| 料金プラン | プラン3種・入会金などの明細 |
| 五大精神と「情」 | 五大精神・「情」の解説 |
| よくあるご質問 | 質問と回答（追加/削除可） |
| お知らせ | 日付・カテゴリ・見出し・リンク（追加/削除可） |
| サポーター（協賛） | 写真・協賛プラン・ボタン文言 |
| 最後の申し込み枠 | 見出し・本文・ボタン |
| フッター | 住所・キャッチフレーズ・コピーライト |

## ローカルでの動作確認

```bash
cd site
pnpm install
ADMIN_PASSWORD=任意のパスワード pnpm dev
```

`http://localhost:3000` と `http://localhost:3000/admin` で確認できます。
ローカルでは Blob が無いため保存はできませんが、画面の確認はできます。

## 構成

| パス | 役割 |
|---|---|
| `app/page.tsx` | 公開ページ。`content` の内容をそのまま描画する |
| `app/admin/` | 管理画面（ログイン・編集） |
| `app/api/` | ログイン・コンテンツ保存・画像アップロード |
| `lib/schema.ts` | **管理画面のフォーム定義。**項目を増やすときはここに1行足す |
| `lib/types.ts` | コンテンツの型 |
| `lib/content.ts` | 保存・読み込み（Blob未設定時は既定値にフォールバック） |
| `content/default.json` | 既定のコンテンツ。未保存のときはこれが表示される |

項目を追加したいときは `content/default.json`・`lib/types.ts`・`lib/schema.ts` の3つに追記すれば、
管理画面のフォームは自動で増えます。保存済みの内容は既定値と自動でマージされるため、
項目を増やしても既存の編集内容は壊れません。

## 未確定のまま残している項目

写真・料金・曜日・時間・会場・住所・電話番号・指導者名・遠征データは、すべてプレースホルダーです。
管理画面から順次差し替えてください。
